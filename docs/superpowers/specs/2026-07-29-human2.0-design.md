# human2.0 — Landing Page Design

**Date:** 2026-07-29
**Status:** Approved
**Scope:** MVP marketing landing page with PayPal placeholder (UI only, no backend payment integration)

## Purpose

A monthly subscription membership community focused on using AI in business. Topics range from self-hosted AI infrastructure (openclaw-style servers) to running the latest AI video creation models and everything in between. The landing page must communicate the vision, showcase content scope, and convert visitors into subscribers via a PayPal subscription button.

## Audience

Operators, founders, and business builders who want to ship AI-augmented businesses. Tech-fluent but not necessarily machine-learning specialists. Want practical, tactical knowledge, framed as a community of practice.

## Brand Decisions

- **Name:** human2.0
- **Tagline / Hero headline:** "The next version of you runs on AI."
- **Tone:** Bold, declarative, futuristic. Visionary messaging grounded in practical operator language.
- **Aesthetic:** Dark futuristic — near-black background, electric cyan primary accent (#00E5FF), violet secondary (#8B5CF6), soft glow effects, animated gradient mesh.

## Tech stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
- **Hosting target:** Vercel (Fluid Compute)
- **No backend in this milestone** — landing page is static. PayPal button is a styled placeholder (gold-button UI hook ready to wire to PayPal Client SDK later).

## Page structure (single route `/`)

1. **Top marquee ticker** — infinite-scroll horizontal strip announcing recent content drops
2. **Hero** — headline, subhead, price card, PayPal button, animated orbital visual
3. **"What you get inside"** — 2x2 grid of benefit cards
4. **"Topics we cover"** — 6 topic cards/chips
5. **Vision manifesto** — large pull-quote block
6. **Stats row** — 3 stat tiles (members, workshops, tracks)
7. **FAQ** — 4 questions in accordion
8. **Final CTA** — repeat price card + PayPal button
9. **Footer** — copyright + placeholder nav links

## Pricing (UI)

- Single tier, monthly subscription
- Display price: **$29/month**
- Reassurance microcopy: "Cancel anytime. Stay forever."

## Content draft (locked copy)

- **Headline:** The next version of you runs on AI.
- **Subhead:** human2.0 is the operator's community for shipping AI-powered businesses — from self-hosted infrastructure to autonomous agents to the latest video models.
- **Marquee items:** "openclaw server setup • AI video workflows • agent frameworks • private comms • weekly workshops •"
- **Manifesto:** "We're not replacing humans. We're building the augmented operator — the one who ships 10x with AI as a teammate."
- **FAQ:**
  - What do I get? — Full access to the community, weekly workshops, downloadable workflows, private chat.
  - Can I cancel? — Yes, anytime. One click.
  - Do I need a tech background? — No. We cover beginner to advanced paths.
  - What tools do you cover? — openclaw, video models (Sora, Veo, Runway), agent frameworks, voice clones, infra, marketing stacks.

## Symbols of success

- Landing page renders cleanly on desktop and mobile
- PayPal button is visually prominent and styled distinctively (gold)
- Headline reads as bold, visionary, slightly provocative
- Sections flow logically: hook -> value -> topics -> vision -> trust -> convert
- Hard NO on placeholder/TODO copy in final UI

## Out of scope (this milestone)

- Actual PayPal payment flow integration
- Auth / member area
- Real community backend
- CMS integration
- Email capture / newsletter

These are next milestones. The landing page must be deploy-ready with a clear hook point for PayPal SDK wiring.

## Implementation notes

- Use CSS + Tailwind for animations (avoid heavy JS libs for simplicity)
- Components live in `app/components/` or inline in `app/page.tsx`
- Animated visual: pure CSS gradient + transform animations
- Keep page under 200KB JS by default (minimal client-side interactions)
